# Week 2 – Power BI

## Data Modeling, DAX & Sales Dashboard

This week focused on developing an interactive Superstore Sales Dashboard using Power BI.

### Tasks Completed

- Established a star schema data model
- Created customer, product, date, and region dimension tables
- Created relationships between fact and dimension tables
- Created a dedicated `_Measures` table
- Created foundational DAX measures
- Created executive KPI cards
- Created category performance analysis
- Created regional profitability analysis
- Created a sales trend line chart
- Created a decomposition tree
- Configured interactive slicers
- Demonstrated cross-filtering
- Configured drill-down functionality
- Developed the final interactive Superstore Sales Dashboard
