# Week 9 – Housing Data Cleaning & Transformation

## Overview
Week 9 focuses on cleaning and transforming the King County House Sales dataset using Power BI. The dataset was prepared for housing market analysis and the development of a Real Estate Analytics Dashboard in Week 10.

## Objectives
- Import the housing dataset into Power BI.
- Inspect column names and verify data types.
- Check data quality, missing values, and errors.
- Create calculated columns for housing analysis.
- Develop DAX measures.
- Validate the transformed dataset.

## Data Transformation
The following calculated columns were created:
- Sale Year
- Sale Month
- Property Age at Sale
- Price per SqFt
- Total Area
- Is Renovated
- Property Size Category
- Price Category

## DAX Measures
The following measures were created:
- Average House Price
- Average Living Area
- Average Bedrooms
- Average Bathrooms
- Total House Sales
- Median House Price
- Maximum House Price
- Minimum House Price
- Average Price per SqFt
- Average Property Age
- Renovated Property Count

## Validation
The transformed dataset, calculated columns, and DAX measures were checked in Power BI. KPI cards were used to validate selected measures.
