# Week 11 – Automobile Data Cleaning & Transformation using Power BI

## Overview
This project focuses on cleaning and transforming automobile data using Power BI and Power Query.

## Objectives
- Import and inspect automobile data.
- Replace invalid placeholders with null values.
- Correct data types and handle missing values.
- Create calculated columns.
- Group vehicles by different categories.
- Develop DAX measures.

## Data Cleaning and Transformation
- Replaced invalid `?` placeholders.
- Handled missing values using median imputation.
- Corrected numeric data types.
- Created Price per Horsepower.
- Created Power-to-Weight Ratio.
- Created MPG Rating Category.
- Grouped vehicles by Body Style, Drive Wheels, and Fuel System.

## DAX Measures
- Average Price
- Average Horsepower
- Average Engine Size
- Average Highway MPG

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Automobile Dataset

The activity provided practical experience in automobile data cleaning, transformation, calculated columns, grouping, and DAX measures using Power BI.
