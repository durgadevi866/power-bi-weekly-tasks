# Week 10 – Real Estate Analytics Dashboard using Power BI

## Overview
This project develops an interactive Real Estate Analytics Dashboard using Power BI and the King County House Sales dataset prepared in Week 9.

## Objectives
- Analyze real estate sales data.
- Display key performance indicators (KPIs).
- Visualize house price trends.
- Compare property sizes and price categories.
- Analyze renovation status.
- Add interactive slicers for data exploration.

## Dashboard Features
- Average House Price
- Total House Sales
- Median House Price
- Renovated Property Count
- Average House Price by Sale Year
- Average House Price by Property Size
- Number of Houses by Price Category
- Renovated vs Non-Renovated Houses
- Interactive filters for Sale Year, Bedrooms, and Renovation Status

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- King County House Sales dataset

## Conclusion
The project provided practical experience in KPI creation, data visualization, interactive filtering, and dashboard design using Power BI. The dashboard helps users explore housing data and understand real estate trends.
