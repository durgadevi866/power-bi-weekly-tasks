# Week 6 – Power BI Healthcare Analytics Dashboard

## Overview

Week 6 focused on creating an interactive Healthcare Analytics Dashboard using the transformed healthcare data prepared in Week 5.

## Work Completed

- Created DAX measures for healthcare KPIs.
- Created Total Patients measure.
- Created Total Healthcare Revenue measure.
- Created Average Billing Amount measure.
- Created Average Length of Stay measure.
- Created Total Billing Records measure.
- Created Readmission Rate measure.
- Created KPI cards for important healthcare metrics.
- Created charts for insurance providers, gender, medical conditions, age groups, and admission trends.
- Created a demographics matrix.
- Created an age-group distribution chart.
- Added Admission Type analysis.
- Added interactive Insurance Provider slicer.
- Added Admission Type slicer.
- Added Date of Admission range slicer.
- Arranged the visuals into a final interactive dashboard.

## Dashboard Components

The dashboard contains KPI cards, analytical charts, a demographics matrix, and interactive slicers for healthcare analysis.

- `Week-6-Power-BI-Report.pdf` – Week 6 report containing screenshots and explanations.

## Conclusion

The Week 6 Healthcare Analytics Dashboard was successfully developed using Power BI and DAX. The dashboard provides interactive analysis of patients, billing, medical conditions, admission patterns, insurance providers, and other healthcare-related information.
