# Week 3 – Power BI

## Financial Data Import, Transformation & Time Intelligence

This week focused on analyzing Shopify stock market data using Power BI.

### Tasks Completed

- Imported Shopify stock data
- Cleaned and transformed data using Power Query
- Created a dedicated Dim_Date table using CALENDARAUTO()
- Marked Dim_Date as the official Date Table
- Created an active one-to-many relationship
- Created financial DAX measures
- Created Daily Return %
- Implemented DATEADD, TOTALYTD, and SAMEPERIODLASTYEAR
- Created Year → Quarter → Month → Day hierarchy
- Built financial KPI cards
- Created stock price trend analysis
- Created trading volume analysis
- Created daily return analysis
- Built the final Shopify Stock Financial Analysis Dashboard
