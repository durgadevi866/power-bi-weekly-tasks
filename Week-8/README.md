# Week 8 – Student Performance Power BI Dashboard

## Overview

Week 8 focuses on creating an interactive Student Performance Analytics Dashboard using Power BI. The prepared Student Performance dataset was used to analyze academic performance and identify patterns across different student groups.

## Objectives

- Create an interactive Power BI dashboard.
- Analyze overall student performance.
- Compare Math, Reading, and Writing scores.
- Analyze performance based on parental education.
- Compare students with and without test preparation.
- Analyze performance based on lunch type.
- Visualize performance grade distribution.
- Add interactive slicers.
- Create a drill-through Academic Profile page.
- Generate meaningful data-driven insights.

## Dashboard Development

The Week 8 dashboard includes:

- Overall Average Score KPI
- Average Math Score KPI
- Average Reading Score KPI
- Average Writing Score KPI
- Overall Pass Percentage KPI
- Average Score by Subject
- Average Score by Parental Education
- Average Score by Test Preparation Course
- Average Score by Lunch Type
- Performance Grade Distribution

## Interactive Slicers

The following slicers were added:

- Gender
- Race/Ethnicity
- Parental Education
- Lunch Type
- Test Preparation Course
- Subject

These slicers allow users to interactively filter and explore student performance data.

## Drill-Through Academic Profile

An Academic Profile page was created using Student ID as the drill-through field.

The Academic Profile contains:

- Subject Performance
- Average Score
- Performance Grade
- Pass/Fail Result
- Test Preparation Status
- Back Navigation Button

## Key Insights

1. Reading has the highest average score among the three subjects.
2. Students who completed the test preparation course show higher average scores than students who did not.
3. Students with standard lunch have a higher average score than students with free/reduced lunch.
4. Student performance varies across different parental education levels.
5. Most students fall within the passing performance categories.
